# Applied AI Projects

A collection of introductory Machine Learning and Deep Learning projects developed using Python and Google Colab.

## Project 1: Iris Flower Classification
- **Type:** Machine Learning
- **Algorithm:** Logistic Regression
- **Library:** Scikit-learn
- **Dataset:** Iris dataset
- **Objective:** Predict flower species from four numerical measurements.
- **Evaluation:** Test accuracy and classification report.

## Project 2: Fashion-MNIST Classification
- **Type:** Deep Learning
- **Model:** Feed-forward neural network
- **Libraries:** TensorFlow, Keras, NumPy, Matplotlib
- **Dataset:** Fashion-MNIST
- **Objective:** Classify clothing images into ten categories.
- **Evaluation:** Test accuracy and test loss.

## How to Run
1. Open the relevant `.ipynb` notebook in Google Colab.
2. Run the code cells in order.
3. Review the actual evaluation results and predictions.

## Files
- `iris_classification.ipynb`
- `fashion_mnist_deep_learning.ipynb`
- `requirements.txt`
